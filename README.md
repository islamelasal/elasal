# أكاديمية العسال للملاكمة

النسخة الحالية تستخدم Supabase للدخول وحفظ البيانات. راجع [دليل الإعداد](SUPABASE_SETUP.ar.md) لنشر الموقع وربط حساب الإدارة.

## إصدار التخزين المحلي السابق

الموقع العام منشور على GitHub Pages. من القائمة افتح «لوحة الإدارة» واضبط كلمة مرور لأول مرة على الجهاز. إذا كانت هناك بيانات محفوظة من الإصدار القديم في نفس المتصفح، تنقلها اللوحة إلى المخزن المشفّر عند ضبط كلمة المرور.

## الحسابات والحفظ

- تُحفظ عمليات الاشتراكات والحضور والمصروفات تلقائيًا. يعرض «التقارير الشهرية» الحركات وسجل العمليات حسب توقيت القاهرة، مع تنزيل CSV وطباعة أو حفظ PDF ومسودة بريد يدوية.
- البيانات والنسخ الداخلية تُشفّر محليًا وتبقى في المتصفح. يحدّث الحفظ نسخة اليوم أثناء استخدام اللوحة. من «النسخ الاحتياطية» يمكن حفظ نسخة داخلية أو تنزيل ملف مشفّر قابل للاستعادة.
- يلزم فتح ملف النسخة المُنزَّل بكلمة المرور التي كانت سارية عند تنزيله. تُعاد حماية البيانات والنسخ الداخلية عند تغيير كلمة المرور. احتفظ بالملفات وكلمات مرورها خارج المتصفح.
- GitHub Pages يستضيف الصفحات العامة. تشفير هذا الجهاز لا يضيف حساب مدير مركزيًا أو مزامنة بين الأجهزة. الإرسال المجدول أثناء إغلاق المتصفح يتطلب خدمة تُشغّل المهام في الخلفية.

## النشر

يرتبط الموقع بفرع `main` من جذر المستودع. رابط الصفحات [أكاديمية العسال](https://islamelasal.github.io/elasal/).
