# أكاديمية العسال للملاكمة

واجهة عربية على GitHub Pages، مع صفحات التدريب ومعرض الصور والفروع. إصدار الربط بقاعدة البيانات يستخدم Supabase Auth وحماية RLS. راجع [خطوات تشغيل Supabase وإنشاء أول أدمن](SUPABASE_SETUP.ar.md).

من لوحة الإدارة تستطيع إدارة المشتركين وملفات الاشتراك والمصروفات، وعرض الحسابات الشهرية وحفظ النسخ الاحتياطية، وتحرير النصوص والصور والفروع. يفتح المشترك صفحة «اشتراكي» لقراءة اشتراكه بعد ربط حسابه من الإدارة.
