# نسخة العرض والتجربة — GitHub Pages

هذه نسخة ملفات ثابتة عربية RTL بألوان الهوية الأربعة. لا توجد بها قاعدة بيانات سيرفر أو مهام Cron. الوضع المحلي يحفظ بيانات التجربة في نفس المتصفح ويحتفظ بنسخ محلية أثناء فتح الصفحة؛ مسح بيانات المتصفح يحذفها.

شروط GitHub Pages تمنع استضافة تشغيل النشاط التجاري وSaaS التجاري، وتوصي بعدم إرسال كلمات المرور من صفحات الخدمة. لذلك تشغيل الصالة الفعلي والدخول والنسخ اليومية تكون على نسخة Cloudflare الكاملة. نسخة Pages تفتح رابط Cloudflare بدل عرض دخول المدير داخل GitHub.

## الرفع مرة واحدة

1. أنشئ مستودعًا عامًا جديدًا مثل `ISLAM-ELASAL/elasal-academy`.
2. ارفع **جميع محتويات** هذا الملف المضغوط إلى جذر المستودع، بما فيها مجلد `assets`. لا ترفع ZIP كما هو؛ فكّه أولًا.
3. اختر `Settings → Pages → Deploy from a branch → main → /(root) → Save`.
4. استخدم الرابط الفعلي الذي يظهر في GitHub. عند استخدام الاسم السابق يكون المتوقع `https://islam-elasal.github.io/elasal-academy/`؛ هذا مثال وليس رابطًا منشورًا مسبقًا.
5. للتجربة اضغط «فتح الوضع المحلي على هذا الجهاز» وأدخل بيانات وهمية فقط.
6. لتشغيل الصالة، انشر الحزمة الأخرى `ELASAL-Cloudflare-Free.zip` وفق `README.ar.md` داخلها. ثم ضع رابط Cloudflare في هذه الصفحة واضغط «فتح النظام على Cloudflare». تنتقل الصفحة إلى الخادم قبل إدخال كلمة المرور.

يمكن حفظ رابط Cloudflare مرة واحدة لكل من يفتح الصفحة بوضع أصل الرابط في `API_BASE` داخل `config.js`. أبقِ `DEPLOY_TARGET` على `github-pages-demo`. لا تضع كلمة المرور أو ملفات نسخ الأعضاء أو أي بيانات شخصية في المستودع.

## النسخ الاحتياطي

Cloudflare: نسخة يومية تلقائية حتى مع إغلاق المتصفح، آخر 30 يومًا متحركة، حذف الأقدم عند تشغيل النسخ، تنزيل يدوي واستعادة، ونسخة أمان قبل الاستبدال. يلزم نشر الخادم وتهيئة قاعدتي D1 وSecret المدير أولًا.

GitHub وحده: لا يستطيع تشغيل نسخ سيرفر تلقائية. نسخ IndexedDB المحلية ليست نسخًا داخل استضافة GitHub، ولا تتشارك مع أجهزة أخرى.

## نقل النظام القديم

نزّل JSON من النظام القديم قبل تغيير الرابط. سجّل الدخول على Cloudflare ثم اختر «استعادة النسخة». لا يتم رفع بيانات المتصفح القديمة تلقائيًا. الملفات القديمة التي تتجاوز 10 MB تحتاج تقليل الصور أولًا.
